# Counter Web Application (Flask)

## 📌 Overview

This project is a simple web application built using Flask that demonstrates how to use **sessions** to maintain state in a stateless HTTP environment.

The application tracks:

* Number of times a user visits the page
* A customizable counter value

 
## 🎯 Features

* Count how many times a user visits the homepage
* Increment counter automatically
* Increment counter by +2 using a button
* Reset counter value
* Clear entire session
* Custom increment using user input



## 🧠 Concepts Used

* HTTP is stateless
* Session for storing user data
* Request/Response cycle
* Flask routing
* Form handling (POST requests)

 

## 🛠️ Technologies

* Python
* Flask
* HTML
* Bootstrap (for styling)

 
## 🔗 Routes

1-/: Display visits and counter.
2-/add2:Increment counter by 2 .
3-/reset:Reset counter to 0
4-/destroy_session:Clear session  
5-/add_custom:Increment by custom value
